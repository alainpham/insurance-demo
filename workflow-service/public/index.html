workflow-service

The business process: routes a quote request through pricing, employee tasks and timers.

  • POST /workflows — start the process for a quote request
  • GET /workflows?quoteId= — find the process behind a quote
  • GET /tasks?role=&status= — the employee work queue
  • POST /tasks/:id/claim · POST /tasks/:id/complete
  • POST /workflows/:id/reprice — re-price with employee overrides
  • POST /admin/tick — run the timer sweep now instead of waiting 30s
  • GET /health

The process, in short:

request -> price -> [review by actuary] -> contact -> send -> accepted
                  |                              |         |
           out of appetite                  abandoned   expired
